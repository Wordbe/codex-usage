READ BEFORE INSTALL - Open Anyway Guide

English
=======

CodexUsage is not Apple-notarized yet. macOS may show:

"CodexUsage" Not Opened

If you see that message:
1. Open System Settings.
2. Go to Privacy & Security.
3. Click Open Anyway for CodexUsage.
4. Double-click CodexUsage.app again.
5. Click Open if macOS asks one more time.

Normal install:
1. Double-click CodexUsage.app.
2. CodexUsage installs itself to ~/Applications and starts.

CodexUsage also:
- Copies itself to ~/Applications/CodexUsage.app.
- Creates a login item.
- Links the CLI at ~/.codexusage/bin/codexusage.

CodexUsage does not edit your Codex config.toml or Codex status line unless you enable account switching.

Korean / 한국어
===============

CodexUsage는 아직 Apple notarization을 받지 않았습니다. macOS가 다음 메시지를 보여줄 수 있습니다.

"CodexUsage" Not Opened

이 메시지가 나오면:
1. 시스템 설정을 엽니다.
2. 개인정보 보호 및 보안으로 이동합니다.
3. CodexUsage의 그래도 열기를 누릅니다.
4. CodexUsage.app을 다시 더블클릭합니다.
5. macOS가 다시 묻는 경우 열기를 누릅니다.

일반 설치:
1. CodexUsage.app을 더블클릭합니다.
2. CodexUsage가 ~/Applications에 설치되고 실행됩니다.

CodexUsage가 추가로 하는 일:
- 자신을 ~/Applications/CodexUsage.app으로 복사합니다.
- 로그인 항목을 생성합니다.
- CLI를 ~/.codexusage/bin/codexusage에 연결합니다.

CodexUsage는 계정 전환을 켜지 않는 한 Codex config.toml 또는 Codex status line을 수정하지 않습니다.
